# GEN-071.9 — Equivalência e regressão

Status: **IMPLEMENTADA / AGUARDANDO VALIDAÇÃO**

## Objetivo

Criar um gate transversal específico para as capacidades relacionais introduzidas na GEN-071, garantindo que a mesma intenção persistida sobreviva sem divergência entre Designer/contrato, Preview, geração e runtime.

## Invariantes verificadas

O gate usa o caso de referência **Central do Fornecedor** e verifica que:

- a relação `Contrato.fornecedor = page_context.pk` preserva o mesmo `target_field` no Preview e na geração;
- o gerador traduz o campo relacional para o identificador Python compilado antes de emitir o runtime;
- agregações relacionais preservam operação e campo (`count`, `sum(valor)`);
- a ação `Novo contrato` preserva o transporte `Contrato.fornecedor ← Fornecedor atual`;
- o parâmetro de transporte emitido pelo runtime é derivado do contrato compilado (`_ap_context_fornecedor`);
- o entrypoint CRUD e a rota da página avançada `record` compartilham o mesmo ID e `url_name` da página persistida;
- o runtime gerado continua compilável como Python.

## Implementação

Teste transversal:

```text
sistema/test_business_experience_equivalence.py
```

O teste não cria uma segunda configuração de referência. A mesma página persistida é projetada para Preview e geração, e o resultado gerado é então inspecionado no runtime.

## Relação com a GEN-071.8

A GEN-071.8 permanece **EM VALIDAÇÃO MANUAL** até a confirmação completa do cenário com dois fornecedores, dados relacionados isolados, métricas corretas e criação de contrato com fornecedor pré-preenchido.

A GEN-071.9 pode ter seu gate automatizado executado em paralelo, mas não substitui essa prova manual end-to-end.

## Critério de validação

A etapa será marcada como **VALIDADA** somente após o gate automatizado correspondente ser reportado verde.
