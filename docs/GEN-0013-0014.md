# GEN-0013 / GEN-0014

## GEN-0013 — Listagens produtivas

Evoluir as telas de lista geradas para paginação e filtros sem alterar o CRUD existente.

- paginação configurável;
- busca textual via `q`;
- preservação de filtros na navegação;
- contexto `page_obj`, `is_paginated` e `paginator`;
- controles de primeira/anterior/próxima/última página;
- filtros derivados dos campos simples da entidade.

## GEN-0014 — Auditoria mínima

Quando `usar_auditoria` estiver habilitado, materializar infraestrutura mínima de auditoria no projeto gerado, sem acoplar a geração a uma implementação externa.

- modelo de auditoria;
- usuário, ação, entidade e identificador do registro;
- data/hora;
- representação resumida dos valores;
- integração com operações CRUD;
- não gerar auditoria quando desabilitada.

Ambas as fases devem preservar os Quality Gates existentes e manter o projeto gerado executável.
